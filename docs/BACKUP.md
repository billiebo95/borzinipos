# Резервное копирование и восстановление

## Создание копии

**Настройки → Резервное копирование и восстановление → «Создать резервную копию»**. Система
попросит выбрать, куда сохранить файл (стандартный выбор Android — можно выбрать Google Drive,
локальную память, другое приложение-хранилище). Файл — обычный JSON, содержит все товары,
категории, рецептуры, склад, закупки, чеки, возвраты, расходы и цели, а также номер версии
формата.

Фоновая синхронизация тоже сама обновляет копию `borzini_backup_latest.json` в папке BORZINI на
Google Drive при каждой успешной синхронизации — это не отменяет ручное резервное копирование.

## Восстановление

**Настройки → «Восстановить из копии»** → выберите файл. Приложение покажет дату копии и что в
ней содержится (сколько товаров, чеков и т.д.) и попросит подтверждение. Перед заменой данных
автоматически создаётся защитная копия текущего состояния (путь показывается после
восстановления) — если восстановили не то, можно вернуть текущие данные обратно тем же способом.

Копия с несовместимой версией формата будет отклонена с понятным сообщением, а не молча
испорчена.

## Экспорт в CSV

Там же — отдельные кнопки для продаж, склада и расходов за текущий месяц. Файлы в кодировке
UTF-8 с BOM и разделителем «;» — открываются в Excel с русскими буквами без «кракозябр» сразу,
без дополнительных настроек кодировки.

# Быстрый старт: закупка → рецептура → продажа → прибыль

## 1. Добавить закупленные ингредиенты и упаковку на склад

**Склад → значок «+»**. Заполните название, категорию, единицу измерения (шт/г/мл), минимальный
остаток. Сохраните — остаток появится с нулём, это нормально: сама закупка проводится отдельно.

**Склад → Закупки → «+»**. Укажите поставщика, затем для каждой позиции — сколько упаковок,
сколько базовых единиц в одной упаковке (например, 1 упаковка стаканов = 50 шт, 1 бутылка сиропа
= 1000 мл) и цену одной упаковки. Нажмите **«Провести закупку»** — только после этого остаток и
себестоимость на складе обновятся. «Сохранить черновик» ничего на складе не меняет.

## 2. Создать напиток с рецептурой

**Настройки → Товары → «+»** (или через кнопку в самой карточке товара). Укажите название,
категорию, а для каждого размера — цену и состав: выберите ингредиенты со склада и их количество
на одну порцию. Себестоимость порции считается автоматически и видна прямо в редакторе.

Для товара без рецептуры (например, бутылка воды) включите переключатель «Простой товар» и
укажите, какую позицию склада списывать — по одной штуке за продажу.

## 3. Продать через кассу

На экране **Касса** нажмите на карточку товара — если у него один вариант, он сразу добавится в
заказ; если несколько размеров — появится выбор. Количество и итог видны внизу экрана (на
планшете — сбоку). Нажмите **«К оплате»**, выберите способ (наличные — с расчётом сдачи,
безналичные — подтверждение оплаты) и завершите продажу. Списание склада происходит именно в
этот момент, не при добавлении в корзину.

## 4. Посмотреть прибыль

**Статистика** — выберите период (сегодня/вчера/неделя/месяц), там будут выручка отдельно по
наличным/безналу, себестоимость, валовая и чистая прибыль (уже с учётом расходов из
**Настройки → Расходы**), средний чек, топ товаров, продажи по категориям и график по дням недели.
